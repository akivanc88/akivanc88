### 🏠 RentAdvise: flagship project
**An AI assistant for British Columbia housing law.** Tenants and landlords ask plain-language questions and get grounded, cited answers about their rights: rent increases, notices, deposits, renovictions.

🔗 **Live:** [rentadvise.ca](https://rentadvise.ca) &nbsp;•&nbsp; also available as an app inside **Claude** and **ChatGPT**

What's under the hood:
- **RAG over real law**: embeddings + Postgres vector search over BC tenancy legislation and RTB forms, refreshed by nightly data pipelines (PDF scraping, OCR, Reddit ingestion).
- **MCP server + custom widgets**: the same assistant runs natively inside Claude and ChatGPT, with interactive UI components.
- **Production-grade**: Google/Facebook OAuth, Stripe billing, rate limiting, e2e tests, deployed on Railway with cron jobs.

*I owned the product, the design calls, and most of the engineering, built solo with AI pair-programming (Claude Code, GPT). Being AI-native isn't a talking point for me; it's how this got shipped.*

**Stack:** TypeScript · React · Node/Express · PostgreSQL + pgvector · Drizzle · OpenAI · MCP · Stripe · Railway
